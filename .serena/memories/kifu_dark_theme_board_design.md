# ダークテーマにおける碁盤デザインと視認性改善

## 課題
- 従来のダークテーマでは、盤面色（`--wc-board`）が暗いくすみ紫（`#504150`）や深緑（`#23302c`）となっており、黒石（`#1c171c`）との明度差がほとんどなく黒石が同化して見えにくかった。
- また、格子線や星、外枠線が白系テキスト色（`var(--wc-text)`）で描画され、ネガポジ反転したような不自然な見た目になっていた。
- さらに、石のドロップシャドウの `flood-color` に `var(--wc-text)` が使われていたため、ダークモード時に石の周囲が白く発光するゴーストシャドウが発生していた。

## 解決策
1. **Ash Wood（木肌色）による品位と視認性の両立**:
   - サムネイル画像（OGP画像）で採用されている高品質なミルクティーベージュ（`#ebdac0`）をダークテーマの盤面色（`--wc-board-bg`）として採用。
   - 格子線（`--wc-board-line`）および星（`--wc-board-star`）を引き締まった木炭墨色（`#253530`）に統一。
   - これにより、黒石・白石・格子線のすべてが本物の碁盤と同様のコントラスト比（黒石に対しては約10:1）で明瞭に認識可能となった。
2. **碁石の立体感とシャドウの正常化**:
   - 黒石には漆黒の那智黒石を想起させる光沢ハイライトグラデーションを定義。
   - 白石には蛤白石のマットな質感と繊細なエッジストロークを付与。
   - ドロップシャドウを自然な黒影（`rgba(0, 0, 0, 0.45)`）に是正し、白光り現象を根絶。
3. **一覧タイルプレビュー（プレースホルダー）の刷新**:
   - OGP未生成時にも、サムネイル画像と同じ Ash Wood 盤面のミニ碁盤SVGをタイルいっぱいにレンダリングすることで、ライト・ダークを問わず美しく整然としたタイル一覧を実現。
4. **OGP画像（SVG→Canvas）生成時のCSS変数解決ルール**:
   - SVGをCanvasに描画する際（`<img>`コンテキスト）、DOMのCSS変数は一切参照できないため黒として扱われる。
   - `var(--wc-board-line, var(--wc-text))` のようにフォールバック値付きのネストしたCSS変数がSVG要素内に存在する場合、ナイーブな正規表現 `/[^)]*/` だと内側の括弧で終了し `)` が残って色コードが構文エラー（`#253530)`）となり格子線が消滅する。
   - `resolveCssVars` により内側から再帰的に解決するとともに、`<line>` や盤面 `<rect>` に対しては明示的な属性上書きを行うフェイルセーフを設けること。
