# 棋譜操作のキーボードショートカット設計と入力フォーム保護

## 概要
棋譜詳細・再生画面（`KifuDetail.svelte`）および棋譜作成画面（`KifuCreator.svelte`）において、マウス操作なしでテンポよく対局棋譜を鑑賞・検討・作成できるよう、キーボードショートカットを実装。

## キーバインド一覧

### 1. 棋譜再生・詳細画面 (`KifuDetail.svelte`)
- **1手進む**: `ArrowRight` / `l` / `L`
- **1手戻る**: `ArrowLeft` / `h` / `H`
- **スペースキー (`Space`)**:
  - 通常時: 1手進む（OGS等の主要囲碁プラットフォーム準拠で最も直感的な操作感）
  - 自動再生中: 自動再生を一時停止
  - `Shift + Space`: 自動再生の開始/停止トグル
- **10手進む**: `ArrowDown` / `j` / `J`
- **10手戻る**: `ArrowUp` / `k` / `K`
- **初手へジャンプ (0手目)**: `Home`
- **最終手へジャンプ**: `End`

### 2. 棋譜作成・編集画面 (`KifuCreator.svelte`)
- **1手進む (Redo)**: `ArrowRight` / `l` / `L`
- **1手戻る (Undo)**: `ArrowLeft` / `h` / `H`
- **スペースキー (`Space`)**:
  - 取り消した局面を戻す（`currentMoveIndex < moves.length - 1` の場合は Redo）
  - 最新局面かつ石が打たれている場合（`moves.length > 0`）: パス（`handlePass()`）
- **初手へジャンプ (0手目)**: `ArrowUp` / `Home`
- **最新手へジャンプ**: `ArrowDown` / `End`

## 重要な設計原則

1. **入力フォームおよびモーダルの完全保護**:
   - `INPUT`, `TEXTAREA`, `SELECT` および `isContentEditable` な要素にフォーカスがある間は、ショートカット処理を直ちに `return` し、対局名やプレイヤー名、添削コメントの文字入力・カーソル移動を絶対に阻害しない。
   - 共有モーダル、設定モーダル、カメラ取り込みモーダル等のダイアログが開いている間も誤爆を防止する。
2. **ブラウザスクロールの抑止 (`e.preventDefault()`)**:
   - 矢印キーやスペースキーが押された際、ブラウザの縦スクロールが発生して画面がブレるのを防ぐため、該当操作時のみ `e.preventDefault()` を発火させる。
3. **Svelte 5 ルーンモードでのリスナー設定**:
   - `<svelte:window onkeydown={handleKeyDown} />` を用いてウィンドウ全体のキー入力をリアクティブかつクリーンにリスニング。
