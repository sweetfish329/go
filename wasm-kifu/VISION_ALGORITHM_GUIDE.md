# 碁盤画像認識 (Go-WASM + OpenCV) 高度化アルゴリズム設計ガイド

本ドキュメントは、NotebookLMの学術調査および実世界の囲碁認識システム（PhotoKifu/VideoKifu, Imago, GBR, img2sgf, Kaya等）の知見に基づき、`wasm-kifu` の画像認識パイプラインを高度化するための設計ガイドおよびアルゴリズム仕様です。

---

## 1. 現状の課題と解決アプローチの全体像

| 課題 | 従来の課題（現状） | NotebookLMによる解決アプローチ |
| :--- | :--- | :--- |
| **照明ムラ・影・木目** | 静的閾値や1D K-meansだけでは「黒石」と「木目の暗い影」の区別が困難 | **ドーナツ走査 ＋ 多次元局所特徴量 $V=[L, C, D, H]$ ＋ 動的平均石比較（Dani Ferrari手法）** |
| **格子線の干渉** | 交点中心をスキャンすると黒い格子線が混ざり偽陽性（空なのに黒石）が発生 | **交点中心を除外したドーナツ状サンプリング** |
| **歪み・たわみ** | 4隅射影変換だけではレンズの歪みや紙碁盤のたわみで交点がズレる | **ガウス過程回帰（GPR / SEカーネル）によるサブピクセル再予測** |
| **石の厚みと視差** | 斜めアングル撮影時に石の上面が手前にシフトする（Parallax） | **アスペクト比（1.077）＋ 3D消失点・二分法幾何最適化** |
| **手や石の遮蔽** | 手や石で4隅や格子線が隠れると認識が破綻する | **ガウス過程の外挿 ＋ 複素交差比（Complex Cross-Ratio）** |
| **動画での手の通過** | 手の通過時に誤認識が多発、361マスの全探索は重く精度が暴落 ($0.99^{361}=2.7\%$) | **オプティカルフロー動的マスク ＋ 静止安定トリガー ＋ ミニマル差分走査** |
| **ルール違反の誤検知** | 誤認識で存在しない手や2手同時着手が検出される | **HMM（隠れマルコフモデル） ＋ 囲碁ルールエンジンの完全統合（ルール違反遷移確率0）** |

## 2. コアアルゴリズム仕様

### ① ドーナツ走査 ＆ 多次元特徴量ベクトル ($V = [L, C, D, H]$)

1. **ドーナツ走査領域の幾何定義**:
   - 外径 $R_{out} = \text{spacing} \times 0.35$
   - 内径 $R_{in} = \text{spacing} \times 0.15$（中心の格子線交差部を完全に除外）
2. **多次元特徴ベクトル $V = [L, C, D, H]$**:
   - **輝度 $L$ (Luminance)**: $L = 0.299R + 0.587G + 0.114B$ (白黒の基本指標)
   - **色度 $C$ (Chrominance)**: RGB値の標準偏差 $\sigma_{RGB}$。碁盤木目は茶・黄色で高色度、石は完全な無彩色で極低色度（影と黒石を完全に分離）。
   - **不均一性 $D$ (Disuniformity)**: 内側から外側へらせん走査した差分累積 $\sum \sqrt{(\Delta L)^2 + (\Delta C)^2}$。空の交点は木目と線で $D$ が高く、石の上は滑らかで $D$ が極めて低い。
   - **色相 $H$ (Hue) & 彩度 $S$**: 色相は影に対して不変、彩度は反射光（グレア）に頑健。

### ② 動的「平均石（Mean Stone）」相対距離アルゴリズム (Dani Ferrari)

時系列で確定している盤面上の石から、現在の画像における代表ベクトルを動的算出：
- $\bar{V}_{Black}$, $\bar{V}_{White}$, $\bar{V}_{Empty}$

対象交点 $V$ に対するユークリッド距離：
$$\text{Dist} = \sqrt{(\Delta L)^2 + (\Delta C)^2 + (\Delta D)^2 + (\Delta H)^2}$$

**判定基準**:
- 基準 (a): $\text{Dist}(V, \bar{V}_{Stone}) \le \frac{2}{3} \text{Dist}(V, \bar{V}_{Empty})$
- 基準 (b): 当該交点と平均石の距離が、全交点を距離順ソートした後続15交点の平均距離の $\frac{2}{3}$ 以下（突出性）
- 基準 (c): 離散導関数（変化率）が後続15交点の平均変化率の 6倍以上（孤立ピーク）

### ③ ミニマル・アプローチ（差分走査）

- 361マスすべてを毎回スキャンするのではなく、前フレームで確定している既知の交点（360箇所）を信頼。
- **未配置の「空の交点」のみを走査対象とする**ことで、計算量を $O(19^2)$ から $O(N_{empty})$ へ削減し、誤検出率の累積 ($0.99^{361} \approx 2.7\% \rightarrow 0.99^{N}$) を劇的に回避。

### ④ 静止安定トリガー ＆ オプティカルフロー

```
[動画フレーム (30fps)]
        │
        ├─→ [オプティカルフロー計算] ──→ 動きの大きい領域（手・腕）を動的マスク
        │
        ├─→ [フレーム間差分 分散計算] ──→ 15〜30フレーム連続で分散 <= 閾値 (静止確定)
        │
        └─→ [静止トリガー発火] ──→ 直前の安定フレームとの差分から「最後の1手」を抽出
                                          │
                                          ↓
                                 [Go WASM ルールエンジン]
                                 ・合法手チェック (自殺手・2重着手排除)
                                 ・アゲハマ判定
```

### ⑤ ガウス過程回帰（GPR）によるサブピクセル歪み補正

- 入力: 論理座標 $(x, y) \in [0, 18]^2$
- 出力: 画像ピクセル座標 $(u, v)$
- カーネル: Squared Exponential (SE) カーネル
  $$k(\mathbf{x}, \mathbf{x}') = \sigma_f^2 \exp\left( -\frac{\|\mathbf{x} - \mathbf{x}'\|^2}{2\ell^2} \right)$$
- 大まかに検出された交点を訓練データとし、事後予測平均（Posterior Mean）でサブピクセル座標を再予測。
- 手や石で遮蔽された交点も、GPモデルの外挿により自動補完。
